# 같이살림 (Salim) PRD

## 목표
커플이 공동 지출의 흐름을 함께 보고, 예산 안에서 관리한다.

## 핵심 기능
- 공동 가계부
- 공동 일정
- 공동 할 일
- 디데이 (홈 카드 + 설정에서 관리)

*(로그인/온보딩은 핵심 기능이 아닌 필수 인프라로 별도 관리)*

---

## 1. 온보딩 및 로그인 (인프라)
- 온보딩 (앱 미설치/미로그인 상태에서 첫 진입 시 노출)
  - 슬라이드 구성: ① 공동 가계부/일정 핵심 가치 소개 → ② 상대방 연결 안내 (초대코드/QR 방식 소개, 이 시점엔 실제 연결 액션 없이 설명만)
  - 마지막 슬라이드에서 "시작하기" → 로그인으로 이동
- 구글 로그인 (카카오 로그인은 추후 적용 예정)
- 로그인 후 상대방 연결 여부와 무관하게 홈 진입 가능
- 미연결 상태에서는 "개인 가계부"처럼 사용 가능 (지출자 필드는 "나"만 존재)
- 홈/설정에 "상대방 연결하기" 배너 상시 노출 (실제 초대코드 입력/QR 연결은 로그인 후 이 배너에서 진행)
- 연결 전 데이터는 개인 데이터로 유지, 연결 후 데이터만 공동 데이터로 전환

- 설정

## 3. 홈
- 달별 지출 종합
- 이번 달 예산 대비 지출 현황 (진행률 + 남은/초과 금액)
  - 예산 카드 탭 시 예산 설정 시트 진입. 금액은 직접 입력과 만원 단위 빠른 금액 버튼(1/5/10/50/100만원, 누적 방식) 중 편한 쪽으로 넣는다.
- 카테고리별 지출 종합
- 다가오는 디데이 (가장 가까운 1~2건, 카드 탭 또는 "전체보기" 탭 시 설정 > 디데이 관리로 이동)
- 최근 지출 내역

## 4. 가계부

가계부 탭 진입 시 기본 화면은 "전체보기"이며, 별도 대시보드 없이 지출 리스트 자체가 탭의 메인 화면 역할을 한다.
- 상단: 월 선택 + 이번 달 총 지출, 검색/필터 아이콘
- 날짜별로 그룹핑된 지출 리스트 (항목 탭 시 지출 수정 화면으로 이동)
- 우측 하단 플로팅 버튼(+)으로 지출 입력 화면 진입

### 지출 입력
- 금액
- 날짜 (기본값 오늘)
- 시간
- 지출자: 우리 / 나 / 상대방 중 택1, **기본값은 나(본인)**
  - "우리"는 둘이 함께 쓴 지출 (한 사람으로 가르지 않음)
  - 나/상대방은 설정 > 프로필에 입력한 이름으로 표시, 이름이 없으면 "나"/"배우자"
- 카테고리
  - 고정 항목(기본: 식비, 카페, 쇼핑, 문화, 여행) — 칩으로 바로 선택. 항상 5개
  - 더보기(기본: 교통, 생활, 의료/건강, 주거/통신, 경조사/선물, 기타) — "+더보기" 탭 시 바텀시트에서 선택
  - 구성과 이름은 설정 > 가계부 카테고리 수정에서 바꾼다. 더보기 시트의 "편집"으로도 들어갈 수 있다
  - 더보기에서 고른 항목은 "+더보기" 칩 자리에 선택 상태로 표시한다 (예: "교통 ▾"). 고정 칩을 고르면 다시 "+더보기"로 돌아간다
- 메모
- ~~자산(현금/체크카드/신용카드/지역화폐)~~ → 1차 범위 제외, 추후 검토

### 지출 수정
- 입력 화면과 동일한 레이아웃 재사용, 기존 값 프리필
- 상단 왼쪽 뒤로가기, 오른쪽 삭제 아이콘
- 삭제 아이콘 탭 시 확인 팝업("삭제하시겠어요?") 노출, 확인 시 삭제 후 이전 화면(전체보기)으로 이동
- 삭제 후 되돌리기(실행취소)는 1차 범위 제외

### 전체보기
- 필터: 기간, 카테고리, 지출자 (금액 범위는 1차 제외)
  - 기간은 **선택한 달 안의 날짜 범위**(시작일~종료일)다. 여러 달에 걸친 조회는 1차 제외 — 달은 상단 월 선택으로 바꾼다
  - 카테고리·지출자는 여러 개를 함께 고를 수 있다. 지출자 필터는 상대방과 연결된 상태에서만 제공
  - 지출자 필터의 "우리"는 따로 고른다 — 나를 골라도 "우리" 지출은 포함하지 않는다
  - 필터 아이콘을 누르면 바텀시트에서 조건을 고르고 "적용하기"로 반영한다
- 검색: 메모 텍스트 (선택한 달 안에서 부분일치, 입력하는 즉시 반영)
- 검색/필터가 걸려 있으면 합계 카드는 **조건에 맞는 지출의 합계와 건수**를 보여주고, 걸린 조건은 칩으로 보여주며 하나씩 해제할 수 있다
- 달을 바꾸면 기간 조건만 풀린다 (다른 달에는 맞지 않으므로). 검색어·카테고리·지출자 조건은 유지
- 정렬: 입력 시간순 (수동 순서 조정 기능은 1차 제외, 필요성 재검토 예정)

## 6. 디데이

별도 탭 없이 **홈 카드(다가오는 1~2건)** 로 보여주고, 전체 목록·추가·수정·삭제는 **설정 > 디데이 관리** 화면에서 한다. (하단 탭 자리는 11. 할 일에 넘김)

- 목록: 가장 가까운 순서로 정렬된 디데이 리스트 (D-day 숫자 강조)
- 데이터 소스 2가지
  - 자동: 설정 > 프로필에 입력한 생일/기념일이 자동으로 목록에 반영
  - 수동: 사용자가 자유롭게 추가 (여행, 이사 등 제한 없음)
- 디데이 추가/수정
  - 제목, 날짜, 반복 여부(매년 반복 / 1회성)
  - 자동 반영된 항목(생일/기념일)은 디데이 관리에서 직접 수정 불가, 설정 > 프로필에서만 수정 가능 (출처 일관성 유지)
- 삭제: 사용자가 직접 추가한 항목만 가능

## 7. 설정
- 상대방 연결/해제
- 프로필 수정 (이름, 생일, 기념일)
  - 이름은 최초 로그인 시 구글 계정 이름으로 채워지고, 이후 사용자가 바꿀 수 있다 (다시 로그인해도 바꾼 이름이 유지된다)
  - 이름은 가계부 지출자 · 할 일 담당자 · 일정 유형 표시(입력 칩 / 리스트 메타)에 사용되고, 연결된 상대방 화면에도 이 이름으로 보인다
  - 입력한 생일/기념일은 디데이(홈 카드 / 디데이 관리)에 자동 반영
- 디데이 관리 (6번 — 디데이 전체 목록·추가·수정·삭제)
- 가계부 카테고리 수정
  - 고정 항목 교체: 고정은 항상 5개. 더보기 항목을 고정으로 올리면 고른 고정 항목 하나와 자리를 맞바꾼다
  - 더보기 항목 추가
  - 이름 수정 (고정/더보기 모두). 최대 8자, 같은 이름 중복 불가. 이름을 바꾸면 기존 지출에도 새 이름으로 보인다
  - 연결된 상태에서는 두 사람이 같은 카테고리 목록을 함께 쓴다 (연결 전 개인 목록은 옮기지 않음)
  - 삭제 대신 "비활성화" 처리 (기존 지출 유지, 목록엔 "사용 중지" 표시) — 1차 범위 밖, 추후 적용
  - 완전 삭제는 해당 카테고리 지출 내역이 없을 때만 허용 — 1차 범위 밖, 추후 적용
- 달별 예산 설정
  - 월 전체 예산만 (카테고리별 예산은 1차 제외)
  - 입력 방식은 홈의 예산 설정 시트와 동일 (직접 입력 + 만원 단위 빠른 금액 버튼)
  - 80% 도달 / 100% 초과 시 알림
- 알림 설정 (종류별 on/off)
- 로그아웃
- 회원탈퇴

## 9. 상대방 연결

두 사람을 하나의 공동 데이터 공간(커플)으로 묶는다. 연결 전 각자 쌓은 기록은 개인 데이터로 그대로 남고, **연결 이후 등록한 기록만 공동 데이터**가 된다 (1번 항목과 같은 원칙).

### 연결 진입점
- 홈 상단 배너 "상대방을 연결해보세요" — 미연결 상태에서 상시 노출, 연결되면 사라진다
- 설정 최상단 연결 상태 카드
- 두 진입점 모두 **연결 관리 화면**으로 간다 (wireframe/connect.md 9-1)

### 초대 코드
- **6자리 영숫자** 코드. 혼동되는 글자(I, L, O, U)는 쓰지 않고, 입력 시 대소문자를 구분하지 않는다 (헷갈리기 쉬운 I·L·O는 입력해도 숫자로 알아서 고쳐 읽는다)
- **유효기간 30분**, **1회용**. 한 사람이 동시에 가질 수 있는 유효 코드는 하나 — 새로 만들면 이전 코드는 즉시 무효가 된다
  - 30분인 이유: 받는 쪽이 앱을 처음 깔고 로그인까지 마쳐야 하는 경우를 감안한 값이다. 인증 코드 관례(5~10분)로는 신규 설치자가 만료를 자주 맞고, 그보다 길면 코드가 살아 있는 시간만 늘어난다
  - 만료는 흔하게 겪는 상태로 보고 다룬다 — 발급 화면에서 한 번의 탭으로 새 코드를 만들 수 있어야 한다
- 발급 화면은 코드·QR·남은 시간을 함께 보여주고, 시스템 공유로 카카오톡 등에 바로 보낼 수 있다. 공유 문구에는 **유효시간을 함께 담아** 받는 쪽이 미루지 않게 한다

### QR 페어링
- 발급 화면의 QR을 상대가 **앱 안에서 스캔**하는 것이 기본 동선
- QR에는 초대 코드가 담긴 딥링크(`salim://invite/{코드}`)가 들어간다. 외부 카메라 앱으로 찍었을 때 앱이 설치돼 있으면 코드 입력 화면으로 바로 진입한다
- 앱 미설치 상태를 위한 웹 랜딩 페이지는 1차 범위에서 제외 (도메인 미보유)

### 연결 성사
- 코드가 확인되면 "○○님과 연결할까요?" 확인 단계를 한 번 거친다. 이때 **기존 개인 기록은 공유되지 않는다**는 점을 함께 안내한다
- 성사 즉시 양쪽 앱의 가계부/일정/할 일/디데이/예산이 공동 경로로 전환된다
- 발급자가 앱을 켜 둔 상태라면 별도 조작 없이 완료 화면으로 넘어간다

### 연결 실패 처리

| 상황 | 처리 |
|---|---|
| 없는 코드 / 오타 | "코드를 다시 확인해주세요" |
| 만료된 코드 | "코드가 만료됐어요. 상대방에게 새 코드를 요청해주세요" |
| 본인이 발급한 코드 | "내가 만든 코드예요" |
| 내가 이미 연결됨 | "이미 연결된 상태예요" |
| 상대가 이미 다른 사람과 연결됨 | "상대방이 이미 다른 분과 연결돼 있어요" |

### 연결 해제 (1차 범위 밖)
- 설정 화면에서 안내
- 해제 시 공동 데이터 즉시 삭제 대신 **유예기간(30일) 보관 후 삭제**
- 유예기간 중 재연결 시 데이터 복원 가능

### 회원탈퇴 (1차 범위 밖)
- 탈퇴 신청 시 상대방에게 알림
- 공동 데이터는 연결 해제와 동일하게 유예기간(30일) 후 삭제
- 유예기간 중 상대방은 열람만 가능, 신규 등록 불가
- 유예기간 종료 후 완전 삭제, 복구 불가

### 1차 구현 범위
연결 성사를 **서버 없이 클라이언트와 Firestore 보안 규칙만으로** 처리한다 (Cloud Functions 미도입 — 운영 비용 0). 그 결과 아래는 다음 단계로 미룬다.

| 항목 | 미루는 이유 |
|---|---|
| 연결 성공 푸시 알림 (8번) | FCM 발송에 서버 트리거가 필요. 발급자 화면의 실시간 감지로 대체 |
| 연결 해제 · 회원탈퇴 | 30일 유예 후 삭제에 스케줄 작업이 필요 |

## 10. 홈 화면 위젯 (OS 위젯)

## 11. 할 일

하단 탭. 둘이 함께 쓰는 체크리스트 (장보기, 집안일, 준비물 등).

- 항목: 제목 + 완료 체크 + 담당자
  - 담당자: 우리 / 나 / 상대방 (이름은 설정 > 프로필 이름, 없으면 "나"/"배우자" — 가계부 지출자와 같은 규칙)
  - 미연결 상태에서는 담당자 선택을 숨기고 본인으로 저장한다
- 목록: 미완료 항목을 등록순으로, 그 아래 "완료" 섹션(접힘/펼침)에 완료 항목을 최근 완료순으로
  - 체크하면 완료 섹션으로 내려가고, 체크를 풀면 미완료로 돌아온다
- 하위 항목: 할 일 하나에 하위 항목(제목 + 완료 체크 + 담당자)을 여러 개 둘 수 있다. **한 단계만** (하위 항목 아래에 또 하위 항목은 없음)
  - 목록에서 상위 항목에 진행 표시("2/5")와 펼침 버튼을 두고, 펼치면 하위 항목을 보고 바로 체크한다
  - 상위 항목을 체크하면 하위 항목도 모두 완료된다. 하위 항목을 모두 체크해도 상위 항목은 직접 체크해야 완료된다. 상위 항목 체크를 풀어도 하위 항목 상태는 그대로 둔다
  - 하위 항목 담당자는 상위 항목과 따로 정한다 (추가할 때 기본값은 상위 항목 담당자)
  - 하위 항목 추가·수정·삭제는 상위 항목의 입력 시트에서 하고, 시트의 저장 버튼으로 함께 저장한다
  - 상위 항목을 삭제하면 하위 항목도 함께 삭제된다
- 추가: 플로팅 버튼(+) → 입력 시트 (제목, 담당자, 하위 항목)
- 수정/삭제: 항목 탭 → 같은 시트에 기존 값 프리필, 삭제는 확인 팝업 후 처리 (되돌리기 없음)
- 연결 상태에서는 두 사람이 같은 목록을 실시간으로 함께 본다. 연결 전 개인 목록은 공동 목록으로 옮기지 않는다 (가계부·일정과 같은 데이터 정책)
- 1차 제외: 마감일, 알림, 순서 수동 조정, 완료 항목 일괄 삭제
