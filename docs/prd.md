# 같이살림 (Salim) PRD

## 목표
커플이 공동 지출의 흐름을 함께 보고, 예산 안에서 관리한다.

## 핵심 기능
- 공동 가계부
- 공동 일정
- 디데이

*(로그인/온보딩은 핵심 기능이 아닌 필수 인프라로 별도 관리)*

---

## 1. 온보딩 및 로그인 (인프라)
- 온보딩 (앱 미설치/미로그인 상태에서 첫 진입 시 노출)
  - 슬라이드 구성: ① 공동 가계부/일정 핵심 가치 소개 → ② 상대방 연결 안내 (초대코드/QR 방식 소개, 이 시점엔 실제 연결 액션 없이 설명만)
  - 마지막 슬라이드에서 "시작하기" → 로그인으로 이동
- 구글 로그인 (카카오 로그인은 추후 적용 예정)
- 로그인 후 상대방 연결 여부와 무관하게 홈 진입 가능
- 미연결 상태에서는 "개인 가계부"처럼 사용 가능 (지출자 필드는 "나"만 존재)
- 홈/설정에 "상대방 연결하기" 배너 상시 노출 (실제 초대코드 입력/QR 연결은 로그인 후 이 배너에서 진행)
- 연결 전 데이터는 개인 데이터로 유지, 연결 후 데이터만 공동 데이터로 전환

## 2. 메인 화면 구성
- 홈
- 가계부
- 일정
- 디데이
- 설정

## 3. 홈
- 달별 지출 종합
- 이번 달 예산 대비 지출 현황 (진행률 + 남은/초과 금액)
- 카테고리별 지출 종합
- 다가오는 디데이 (가장 가까운 1~2건, 탭하면 디데이 탭으로 이동)
- 최근 지출 내역

---

## 4. 가계부

가계부 탭 진입 시 기본 화면은 "전체보기"이며, 별도 대시보드 없이 지출 리스트 자체가 탭의 메인 화면 역할을 한다.
- 상단: 월 선택 + 이번 달 총 지출, 검색/필터 아이콘
- 날짜별로 그룹핑된 지출 리스트 (항목 탭 시 지출 수정 화면으로 이동)
- 우측 하단 플로팅 버튼(+)으로 지출 입력 화면 진입

### 지출 입력
- 금액
- 날짜 (기본값 오늘)
- 시간
- 지출자 (나, 배우자)
- 카테고리
- 메모
- ~~자산(현금/체크카드/신용카드/지역화폐)~~ → 1차 범위 제외, 추후 검토

### 지출 수정
- 입력 화면과 동일한 레이아웃 재사용, 기존 값 프리필
- 상단 왼쪽 뒤로가기, 오른쪽 삭제 아이콘
- 삭제 아이콘 탭 시 확인 팝업("삭제하시겠어요?") 노출, 확인 시 삭제 후 이전 화면(전체보기)으로 이동

### 전체보기
- 필터: 기간, 카테고리, 지출자 (금액 범위는 1차 제외)
- 검색: 메모 텍스트
- 정렬: 입력 시간순 (수동 순서 조정 기능은 1차 제외, 필요성 재검토 예정)

## 6. 디데이

핵심 기능으로 별도 탭 구성. 설정의 "디데이 관리"에서 이관.

- 목록: 가장 가까운 순서로 정렬된 디데이 리스트 (D-day 숫자 강조)
- 데이터 소스 2가지
  - 자동: 설정 > 프로필에 입력한 생일/기념일이 자동으로 목록에 반영
  - 수동: 사용자가 자유롭게 추가 (여행, 이사 등 제한 없음)
- 디데이 추가/수정
  - 제목, 날짜, 반복 여부(매년 반복 / 1회성)
  - 자동 반영된 항목(생일/기념일)은 이 탭에서 직접 수정 불가, 설정 > 프로필에서만 수정 가능 (출처 일관성 유지)
- 삭제: 사용자가 직접 추가한 항목만 가능

---

## 7. 설정
- 상대방 연결/해제
- 프로필 수정 (생일, 기념일) — 입력한 생일/기념일은 디데이 탭에 자동 반영
- 가계부 카테고리 수정
  - 삭제 대신 "비활성화" 처리 (기존 지출 유지, 목록엔 "사용 중지" 표시)
  - 완전 삭제는 해당 카테고리 지출 내역이 없을 때만 허용
- 달별 예산 설정
  - 월 전체 예산만 (카테고리별 예산은 1차 제외)
  - 80% 도달 / 100% 초과 시 알림
- 알림 설정 (종류별 on/off)
- 로그아웃
- 회원탈퇴

---

## 8. 알림

| 종류 | 발생 시점 |
|---|---|
| 상대방 지출 등록 | 배우자가 지출 등록 시 |
| 예산 임박 | 월 예산 80% 도달 |
| 예산 초과 | 월 예산 100% 초과 |
| 일정 알림 | 당일 또는 전날 (설정 가능) |
| 디데이 알림 (생일/기념일/직접 추가) | 3일 전 + 당일 |
| 상대방 연결 성공 | 페어링 완료 시 |

> 구현 참고: 상대방 액션 기반 알림(지출 등록, 예산 초과, 연결 성공 등)은 클라이언트 단독으로는 발송 불가하며 서버 트리거(Firebase Cloud Functions)가 필요하다. (CLAUDE.md 3번 섹션 참고)

---

## 9. 상대방 연결

### 연결하기
- 로그인 후 홈 또는 설정에서 안내
- 초대 코드, QR 페어링
- 연결 성공 시 알림

### 연결 해제
- 설정 화면에서 안내
- 해제 시 공동 데이터 즉시 삭제 대신 **유예기간(30일) 보관 후 삭제**
- 유예기간 중 재연결 시 데이터 복원 가능

### 회원탈퇴
- 탈퇴 신청 시 상대방에게 알림
- 공동 데이터는 연결 해제와 동일하게 유예기간(30일) 후 삭제
- 유예기간 중 상대방은 열람만 가능, 신규 등록 불가
- 유예기간 종료 후 완전 삭제, 복구 불가

## 10. 홈 화면 위젯 (OS 위젯)
- iOS/Android 홈 화면에 추가 가능한 위젯 제공
- 표시 정보: 가장 가까운 디데이 1건 (예: "결혼기념일 D-12")
- 위젯 탭 시 앱 실행 후 해당 디데이 상세로 이동
- 위젯 크기: 소형 1종으로 시작 (확장 필요 시 중형에 디데이 여러 건 표시 검토)
- 디데이가 하나도 없을 경우 "디데이를 추가해보세요" 빈 상태 노출

## 남은 결정 필요 사항
- 카테고리별 예산 향후 도입 여부
- 지출 순서 수동 조정 기능의 실제 필요성
- 위젯 중형 사이즈(예산 현황 등 추가 정보) 도입 여부
- 디데이 탭과 하단 5개 탭 구성이 UI상 복잡해지지 않는지 (아이콘/라벨 검토 필요)
- Cloud Functions 운영 비용 및 콜드스타트 지연이 알림 체감 속도에 미치는 영향 검토
