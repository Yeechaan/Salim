# 12. 결혼 준비

결혼 준비는 하단 탭이 없다. **설정 > 결혼 준비**를 켜면 홈에 결혼 준비 카드(home.md 2-2)가 나타나고, 카드를 누르면 아래 12-1 화면으로 들어간다. (PRD 12)

웨딩 지출은 가계부와 완전히 분리된다 — 월 예산·홈 통계·가계부 전체보기·예산 위젯 어디에도 잡히지 않는다. 화면에서도 "웨딩 예산", "웨딩 지출"처럼 이름을 붙여 가계부와 헷갈리지 않게 한다.

## 12-1. 결혼 준비 (메인 화면)

### 진입
- 홈 결혼 준비 카드 탭 (home.md 2-2)

### 화면 목적
예식까지 남은 시간, 준비 진행 상황, 쓴 돈을 한 화면에서 보고 세부 관리로 들어간다.

### 레이아웃 (위→아래 순서)
1. **상단** — 좌측 뒤로가기, 타이틀 "결혼 준비". 하위 화면이라 하단 탭바는 없다
2. **요약 카드**
   - 첫 줄: 예식일 "2027년 5월 22일 (토)" + 우측 D-day 배지 ("D-238", 당일 "D-DAY", 지나면 "D+3")
     - 미정이면 "예식일을 정해보세요" + 우측 화살표
     - 줄 탭 → 날짜 선택 팝업. 예식일이 있을 때는 팝업 좌측 하단에 "미정으로" 버튼 (날짜를 비운다)
   - 구분선 아래 두 칸 나란히
     - 체크리스트: "12 / 30 완료" + 얇은 진행률 바
     - 웨딩 예산: "68% 사용" + 얇은 진행률 바 (지출 완료 기준, 100% 초과 시 경고색). 예산이 없으면 "예산 미설정"
   - 두 칸은 장식이 아니라 탭 영역 — 탭하면 해당 세그먼트로 전환
3. **세그먼트** — "체크리스트 / 예산 / 업체" 3칸. 기본은 체크리스트, 마지막으로 본 세그먼트를 기억한다 (이 기기에만)
   - 요약 카드와 함께 스크롤되다가 상단에 닿으면 고정(sticky)
4. **세그먼트 내용** — 12-2 / 12-4 / 12-6
5. **플로팅 액션 버튼 (+)** — 세그먼트에 따라 동작이 바뀐다
   - 체크리스트 → 12-3 항목 추가 시트
   - 예산 → 12-5 웨딩 지출 기록
   - 업체 → 12-8 업체 추가

### 상태 분기
- 설정에서 결혼 준비를 끄면(상대방이 끈 경우 포함) 이 화면에 있더라도 홈으로 돌아간다

## 12-2. 체크리스트 (세그먼트)

### 레이아웃 (위→아래 순서)
- **시기 그룹 카드**를 순서대로 나열: 12~6개월 전 / 6~3개월 전 / 3~1개월 전 / 1개월~1주 전 / 1주 이내
  - 그룹 헤더: 그룹명 + 진행 "3/5" + 우측 펼침/접힘 화살표. 현재 시기 그룹은 그룹명 옆에 "지금" 배지 (옅은 칩)
  - 항목 구성: 할 일(todo.md 11-1)과 같은 줄 — 좌측 원형 체크박스 + 제목 + (연결 상태에서만) 담당자 메타
  - 그룹 안에서 미완료는 등록순, 그 아래 완료 항목을 최근 완료순으로 (체크박스 Coral 채움, 제목 취소선 + Muted). 완료 섹션을 따로 접지 않는다
  - 체크박스 탭 → 완료/해제. 체크박스 외 영역 탭 → 12-3 수정 시트
  - 항목이 하나도 없는 그룹은 숨긴다

### 펼침 규칙
- 예식일이 있으면 **현재 시기 그룹만 펼치고** 나머지는 접는다. 지난 그룹에 미완료가 남아 있으면 헤더 진행 표시를 Coral로 (놓친 일이 있다는 표시)
- 예식일이 미정이면 모든 그룹을 펼친다
- 사용자가 펼치거나 접은 상태는 화면에 머무는 동안만 유지한다 (다시 들어오면 위 규칙으로)

### 현재 시기 그룹 판정 (예식일 기준, 달력 날짜로 계산)
| 오늘이 | 현재 그룹 |
|---|---|
| 예식일 6개월 전 날짜 이전 (12개월보다 더 전 포함) | 12~6개월 전 |
| 6개월 전 ~ 3개월 전 날짜 이전 | 6~3개월 전 |
| 3개월 전 ~ 1개월 전 날짜 이전 | 3~1개월 전 |
| 1개월 전 ~ 7일 전 날짜 이전 | 1개월~1주 전 |
| 7일 전 이후 (예식일이 지난 뒤 포함) | 1주 이내 |

### 기본 항목 (처음 켤 때 한 번만 채움, 초안 — PRD 12-3 확정 필요)
| 시기 그룹 | 항목 |
|---|---|
| 12~6개월 전 | 상견례, 예식장 계약, 스드메 계약 |
| 6~3개월 전 | 신혼여행 예약, 예물·예단 준비, 혼주 한복/예복 |
| 3~1개월 전 | 청첩장 제작, 식순·사회자 섭외 |
| 1개월~1주 전 | 청첩장 발송, 최종 인원 확정 |
| 1주 이내 | (없음) |

- 기본 항목의 담당자는 "우리". 사용자가 추가한 항목과 똑같이 수정·삭제할 수 있다
- 기본 항목은 **커플(또는 미연결 개인)마다 한 번만** 채운다. 껐다 켜도, 모두 지워도 다시 채우지 않는다

### 상태 분기
- 항목이 하나도 없음: "체크리스트를 추가해보세요" 빈 상태
- 미연결: 담당자 메타를 숨긴다

## 12-3. 체크리스트 항목 추가 / 수정 (바텀시트)

할 일 시트(todo.md 11-2)와 같은 형태에서 하위 항목을 빼고 시기를 더했다.

### 레이아웃 (위→아래 순서)
1. **타이틀** — "항목 추가" / "항목 수정". 수정일 때만 우측 삭제(휴지통) 아이콘
2. **제목 입력** — 한 줄, 자동 포커스, placeholder "할 일을 입력하세요", 최대 30자
3. **시기** — 5개 그룹 칩 중 택1 (`ChipFlowRow`). 추가 시 기본값은 현재 시기 그룹, 예식일 미정이면 "12~6개월 전"
4. **담당자** — "우리" / 내 이름 / 상대 이름 칩. 기본값 "우리". 미연결 상태에서는 숨기고 본인으로 저장
5. **하단 버튼** — "저장하기" / "수정 완료". 제목이 비어 있으면 비활성

### 동작
- 시기를 바꾸면 그 그룹으로 옮겨 간다. 그룹 안 순서는 등록순이라 맨 아래로 가지 않고 원래 등록 시각 자리에 들어간다
- 삭제·시트 내리기·상대방 삭제 처리는 할 일 시트와 같다

## 12-4. 예산 (세그먼트)

### 레이아웃 (위→아래 순서)
1. **웨딩 예산 카드**
   - "웨딩 예산" 라벨 + 우측 연필 아이콘 (홈 예산 카드와 같은 형태, 카드 전체가 탭 영역)
   - 지출 완료 금액 강조 + "/ 총 예산" 보조
   - 진행률 바: 지출 완료분은 Peach→Coral, 이어서 **지출 예정분은 옅은 Coral**(Primary Soft)로 채운다
   - 아래 3줄 (라벨 좌 / 금액 우)
     - 지출 완료 — 기록한 웨딩 지출 합계
     - 지출 예정 — 계약 완료 업체의 남은 금액 합계 (12-7)
     - 남은 금액 — 총 예산 − 지출 완료 − 지출 예정. 0보다 작으면 라벨 "초과 예상" + 경고색
   - 지출 완료가 예산의 100%를 넘으면 진행률 바를 경고색으로 (홈 예산 카드와 같은 규칙)
   - 카드 탭 → 예산 입력 시트 (`BudgetInputSheet` 공용, 타이틀 "웨딩 예산")
2. **항목별 지출 카드**
   - 웨딩 항목 6개를 고정 순서로 모두 나열: 예식장 · 스드메 · 예물·예단 · 혼수 · 신혼여행 · 기타
   - 줄 구성: 항목 아이콘 배지 + 항목명 + 우측 지출 완료 금액. 지출 예정이 있으면 금액 아래 Caption "예정 1,200,000원"
   - 탭 동작 없음
3. **지출 내역**
   - 섹션 제목 "지출 내역" + 건수
   - 날짜별 그룹 리스트, 최근 날짜가 위. 달 구분 없이 전체를 보여준다
   - 항목 구성: 항목 아이콘 + 제목 + 메타 + 금액
     - 제목: 메모 → 업체명 → 항목명 순으로 있는 것
     - 메타: 항목 · 업체(있으면) · (연결 상태에서만) 지출자
   - 항목 탭 → 12-5 수정

### 상태 분기
- 웨딩 예산 미설정: 카드 첫 줄을 "웨딩 예산을 설정해보세요" CTA로 바꾸고 진행률 바를 숨긴다. 지출 완료·지출 예정 줄은 그대로, 남은 금액 줄은 숨긴다
- 기록한 지출 없음: 지출 내역 자리에 "아직 기록한 지출이 없어요"

## 12-5. 웨딩 지출 기록 / 수정

가계부 지출 입력·수정(expense.md 4-2, 4-3)과 같은 레이아웃을 쓰고, 입력 항목만 다르다.

### 진입
- 12-4 FAB / 12-4 지출 내역 항목 탭(수정)
- 12-7 업체 상세 "지출 기록" 버튼 / 업체 지출 목록 항목 탭(수정)

### 레이아웃 (위→아래 순서)
1. **상단** — 기록: 닫기(X) + "웨딩 지출 기록" / 수정: 뒤로가기 + "웨딩 지출 수정" + 우측 삭제 아이콘
2. **금액 강조 영역** — 가계부 지출 입력과 같다
3. **입력 필드**
   - 날짜 (기본값 오늘). 시간은 받지 않는다 — 같은 날짜 안에서는 입력한 순서
   - 웨딩 항목 — 6개 칩 모두 노출 (`CategoryChip`, `ChipFlowRow`). 필수
   - 업체 — FieldRow, 값 "선택 안 함" 기본. 탭 → 바텀시트: 맨 위 "선택 안 함" + 업체를 웨딩 항목별로 묶어 나열
     - 업체를 고르면 웨딩 항목이 그 업체의 항목으로 맞춰진다. 이후 항목을 바꿔도 업체는 그대로 둔다
     - 업체가 하나도 없으면 시트에 "등록된 업체가 없어요" 문구만
   - 지출자 — 가계부 지출자와 같은 규칙 ("우리" / 내 이름 / 상대 이름, 기본 본인, 미연결 시 숨김)
   - 메모
4. **하단 고정 버튼** — "저장하기" / "수정 완료". 금액이 0이거나 웨딩 항목을 안 골랐으면 비활성

### 동작
- 업체 상세에서 들어오면 업체·웨딩 항목이 미리 채워지고, 저장 후 업체 상세로 돌아간다
- 삭제 플로우는 가계부 지출 수정과 같다 (확인 팝업 "삭제하시겠어요?" / "삭제하면 되돌릴 수 없어요.")
- 수정 중 상대방이 그 지출을 지우면 이전 화면으로 돌아간다

---

## 12-6. 업체 (세그먼트)

### 레이아웃 (위→아래 순서)
- **웨딩 항목별 그룹 카드** — 12-4와 같은 항목 순서, 업체가 없는 항목은 숨긴다
  - 그룹 헤더: 항목 아이콘 + 항목명
  - 그룹 안 순서: 계약 완료 → 상담 중, 각각 등록순
  - 업체 줄 구성
    - 첫 줄: 업체명 + 상태 칩 (계약 완료: Coral 채움 / 상담 중: 옅은 칩)
    - 메타(Caption): 계약 완료 — "계약 3,000,000원 · 남은 1,200,000원 · 잔금 5월 10일" / 상담 중 — "3,000,000원" (계약 금액이 있을 때). 없는 값은 빼고, 모두 없으면 메타 줄을 숨긴다
  - 줄 탭 → 12-7 업체 상세

### 상태 분기
- 업체 없음: "업체를 추가해보세요" 빈 상태

---

## 12-7. 업체 상세

### 레이아웃 (위→아래 순서)
1. **상단** — 좌측 뒤로가기, 타이틀 업체명, 우측 수정(연필) 아이콘 → 12-8 수정
2. **정보 카드** — 줄마다 라벨 좌 / 값 우
   - 웨딩 항목, 상태
   - 연락처 — 값 옆에 전화 아이콘. 줄 탭 → 전화 앱(다이얼 화면)에 번호가 채워진 채로 열린다 (바로 걸지 않는다)
   - 잔금일
   - 메모 (여러 줄)
   - 비어 있는 값의 줄은 숨긴다
3. **금액 카드**
   - 계약 금액 / 기록한 지출 / 남은 금액 (= 계약 금액 − 기록한 지출)
   - 기록한 지출이 계약 금액보다 많으면 남은 금액 줄을 "초과 OOO원" 경고색으로 (지출 예정에는 0으로 잡힌다)
   - 계약 금액이 없으면 기록한 지출 줄만
4. **"지출 기록" 버튼** — 카드 아래 폭 100% 옅은 버튼 → 12-5 (업체 미리 채움)
5. **이 업체 지출 목록** — 날짜 · 제목(메모, 없으면 항목명) · 금액, 최근 날짜가 위. 탭 → 12-5 수정
   - 없으면 "아직 기록한 지출이 없어요"

### 남은 금액과 지출 예정
- 지출 예정(12-4)에 더하는 것은 **상태가 계약 완료**인 업체의 남은 금액(0 미만이면 0)뿐이다. 상담 중 업체의 금액은 견적으로 보고 더하지 않는다

### 상태 분기
- 보고 있는 중에 상대방이 업체를 지우면 업체 목록으로 돌아간다

---

## 12-8. 업체 추가 / 수정

입력 항목이 많아 시트 대신 전체 화면으로 연다 (지출 입력과 같은 구조).

### 레이아웃 (위→아래 순서)
1. **상단** — 추가: 닫기(X) + "업체 추가" / 수정: 뒤로가기 + "업체 수정" + 우측 삭제 아이콘
2. **입력 필드**
   - 업체명 — 한 줄, 자동 포커스, 최대 20자. 필수
   - 웨딩 항목 — 6개 칩 (`CategoryChip`). 필수
   - 상태 — "상담 중" / "계약 완료" 칩. 기본 "상담 중"
   - 연락처 — 전화번호 키패드, 입력하면서 하이픈 자동
   - 계약 금액 — 금액 입력 (천단위 콤마, "원"), 최대 10자리
   - 잔금일 — FieldRow, 기본 "선택 안 함". 탭 → 날짜 선택 팝업 ("선택 안 함" 버튼으로 비울 수 있다)
   - 메모 — 여러 줄
3. **하단 고정 버튼** — "저장하기" / "수정 완료". 업체명이 비었거나 웨딩 항목을 안 골랐으면 비활성

### 동작
- 추가 저장 → 업체 목록으로. 수정 완료 → 업체 상세로
- 삭제 → 확인 팝업 "삭제하시겠어요?" / "이 업체로 기록한 지출 N건은 남아요." (지출이 없으면 "삭제하면 되돌릴 수 없어요.") → 삭제 후 업체 목록으로 (상세를 건너뛴다)
  - 남은 지출은 업체 표시만 빠진다 (PRD 12-5)

## 상태 분기 (추후 확정 필요)
- 예식일이 지난 뒤 홈 카드·이 화면 처리 (PRD 남은 결정 사항) — 1차는 D+N 표시로 그대로 둔다
- 웨딩 예산 입력 시트의 빠른 금액 버튼 단위 — 웨딩 예산은 수천만 원대라 `+1만`~`+100만`으로는 누르기 번거롭다. 1차는 PRD대로 같은 시트를 쓰고 직접 입력에 기대며, 단위 조정(예: `+100만`~`+1000만`)은 PRD 확인 후
- 미연결 상태에서 쓰던 결혼 준비 데이터는 연결 후 옮기지 않는다 (PRD 12-6). 연결 직후 공동 공간은 비어 있고 결혼 준비도 꺼진 상태로 시작한다 — 기본 항목은 공동 공간에서 켤 때 새로 채운다
