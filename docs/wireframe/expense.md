# 4. 가계부

가계부 탭은 별도 대시보드 없이, 아래 "전체보기" 화면이 탭의 기본(랜딩) 화면 역할을 한다.

## 4-1. 전체보기 (탭 랜딩 화면)

### 화면 목적
이번 달 지출을 날짜순으로 훑어보고, 새 지출을 빠르게 추가하는 화면.

### 레이아웃 (위→아래 순서)
1. **상단 - 월 선택 + 액션 아이콘**
   - 좌: "2026년 8월" + 드롭다운 (월 변경)
   - 우: 검색 아이콘, 필터 아이콘
2. **월 합계 카드**
   - "이번 달 총 지출" 라벨 + 금액
3. **날짜별 그룹 리스트**
   - 날짜 헤더 (예: "8월 5일 (화)") 아래로 해당 날짜의 지출 항목 나열
   - 항목 구성: 카테고리 아이콘, 상호명/메모, 카테고리·지출자 메타 정보, 금액
   - **지출자는 상대방과 연결된 상태에서만 노출한다.** 미연결이면 모든 지출이 본인 것이라 "나"만 반복되어 의미가 없다
   - 항목 탭 시 지출 수정 화면으로 이동
4. **플로팅 액션 버튼 (+)**
   - 화면 우측 하단 고정, 탭 시 지출 입력 화면으로 이동
5. **하단 탭 내비게이션** (전 화면 공통, "가계부" 강조)

### 검색 (상단바 인라인)
- 검색 아이콘 탭 → 상단바의 "가계부" 타이틀 자리가 검색 입력창으로 바뀐다 (placeholder "메모 검색", 자동 포커스)
  - 좌: 검색 입력창 / 우: 닫기(X) 아이콘, 필터 아이콘
- 입력하는 즉시 리스트가 걸러진다 (선택한 달 안, 메모 부분일치, 대소문자·앞뒤 공백 무시)
- 닫기(X) 탭 → 검색어를 지우고 원래 상단바로 돌아간다

### 필터 (바텀시트)
- 필터 아이콘 탭 → 바텀시트. 조건이 하나라도 걸려 있으면 필터 아이콘을 Coral로 표시
- 시트 구성 (위→아래)
  1. 타이틀 "필터" + 우측 "초기화" 텍스트 버튼 (시트 안의 조건만 비움, 적용 전까지 목록엔 반영 안 됨)
  2. **기간** — "시작일" / "종료일" 두 줄(FieldRow). 기본값 "전체". 탭 시 날짜 선택 팝업, **선택한 달의 날짜만 고를 수 있다**. 시작일이 종료일보다 늦으면 두 값을 맞바꿔 저장
  3. **카테고리** — 전체 카테고리(고정 + 더보기) 칩, 복수 선택. `ChipFlowRow` 줄바꿈
  4. **지출자** — "우리" / 내 이름 / 상대 이름 칩, 복수 선택. 칩은 그 지출자로 저장된 지출만 거른다 (내 이름을 골라도 "우리" 지출은 빠진다). **미연결 상태에서는 이 구역을 숨긴다**
  5. 하단 버튼 "적용하기"
- 시트를 내리면(적용 없이 닫으면) 바꾼 조건은 버린다

### 검색/필터 적용 중 표시
- 월 선택 아래에 **조건 칩 줄** — 기간("8월 3일 ~ 8월 10일"), 카테고리별, 지출자별 칩에 ✕ 아이콘. 탭하면 그 조건만 해제. 검색어는 상단 입력창에 보이므로 칩으로 만들지 않는다
- 월 합계 카드: 라벨 "조건에 맞는 지출 · N건" + 조건에 맞는 합계
- 달을 바꾸면 기간 조건만 풀린다. 검색어·카테고리·지출자는 유지

### 상태 분기
- 해당 월 지출 데이터 없음: 리스트 영역에 "이번 달 지출이 없어요" 빈 상태 노출 (검색/필터 여부 무관)
- 검색/필터 적용 후 결과 없음: "조건에 맞는 지출이 없어요" 문구 + "필터 초기화" 버튼 (검색어와 필터를 모두 비운다)
- 필터를 건 채 연결이 해제되면: 지출자 조건은 무시하고 칩도 숨긴다

### 화면 이동
- 목록 항목 → 지출 수정(4-3) / FAB → 지출 입력(4-2). 돌아와도 검색어·필터는 유지된다

## 4-2. 지출 입력

### 화면 목적
새로운 지출 1건을 빠르게 기록.

### 레이아웃 (위→아래 순서)
1. **상단 - 타이틀만 노출** ("지출 입력"), 좌측에 닫기(X) 아이콘. 별도 저장 버튼은 상단에 두지 않음 (하단 버튼과 중복 방지)
2. **금액 강조 영역**
   - 화면 중앙 상단, 큰 숫자로 금액 표시/입력
   - 숫자는 "원" 바로 앞에 오른쪽 정렬, **"원" 뒤에 여백**을 둬서 화면 끝에 붙지 않게 한다 ("원"의 오른쪽 끝을 아래 카드 안쪽 값 — 날짜·시간 — 의 오른쪽 끝과 맞춘다)
3. **입력 필드 리스트** (구분선으로 구획)
   - 날짜 (기본값: 오늘)
   - 시간
   - 지출자 — 칩 3개 중 택1: "우리" / 내 이름 / 상대 이름. **기본값은 내 이름(본인)**. 이름은 **설정 > 프로필의 이름**(내 쪽)과 상대방 이름을 쓰고, 이름이 없으면 "나" / "배우자"로 떨어진다. 전체보기 리스트와 홈의 최근 지출 메타도 같은 이름을 쓴다 ("우리" 지출은 "우리")
     - "우리"는 둘이 함께 쓴 지출. 칩 순서는 할 일 담당자·일정 유형과 같게 "우리"를 맨 앞에 둔다
     - 이름이 길어 한 줄에 다 안 들어가면 칩을 다음 줄로 넘긴다 (`ChipFlowRow`)
     - **미연결 상태에서는 이 줄 자체를 숨기고 항상 본인으로 저장한다** (PRD 1 "미연결 상태에서는 지출자 필드는 나만 존재")
   - 카테고리 — **고정 칩**(식비 · 카페 · 쇼핑 · 문화 · 여행) + "+더보기" 칩 (PRD 4)
     - 고정/더보기 구성과 이름은 **설정 > 카테고리 수정**에서 바꿀 수 있다 (settings.md 3-2). 위 목록은 기본값
     - 칩은 개수가 아니라 폭 기준으로 줄바꿈한다 (이름 길이가 제각각)
     - 칩마다 라벨 앞에 카테고리 아이콘을 붙인다. 미선택 칩은 가계부 리스트 아이콘과 같은 **카테고리색 옅은 배경 + 색 아이콘**, 선택 칩은 같은 카테고리색을 더 진하게(배경 40% + 같은 색 테두리 + 굵은 글자) (design.md 칩). "+더보기"는 아이콘 없는 연코랄 칩, 더보기 항목을 고르면 그 항목 아이콘과 함께 "교통 ▾" 선택 칩으로 표시
     - "+더보기" 탭 → 바텀시트에 **고정 칩에 없는 항목만** 노출 (기본: 교통 · 생활 · 의료/건강 · 주거/통신 · 경조사/선물 · 기타). 항목 탭 시 선택 후 시트 닫힘
     - 시트 우측 상단 **"편집"** → 카테고리 수정 화면. 돌아오면 고른 카테고리는 유지된다
     - 더보기 항목을 고르면 고정 칩은 모두 해제되고, **"+더보기" 칩이 선택 상태의 "교통 ▾"로 바뀐다**. 이 칩을 탭하면 시트가 다시 열린다 (칩 줄 수는 그대로)
     - 고정 칩을 고르면 다시 "+더보기"로 돌아간다
     ```
     카테고리
     [식비] [카페] [쇼핑]
     [문화] [여행] [●교통 ▾]
     ```
   - 메모 — 텍스트 입력
4. **하단 고정 버튼**: "저장하기"

### 상태 분기 (추후 확정 필요)

## 4-3. 지출 수정

### 화면 목적
기존 지출 1건의 내용을 수정하거나 삭제.

### 레이아웃
- **지출 입력과 동일한 레이아웃을 재사용**, 기존 값이 프리필된 상태로 진입
- 상단: 좌측 뒤로가기 아이콘, 우측 삭제(휴지통) 아이콘으로 교체 (닫기 아이콘 대신)
- 하단 고정 버튼 라벨만 "수정 완료"로 변경
- 저장해도 **목록 순서(입력 시간순)는 바뀌지 않는다** — 등록 시각은 그대로 두고 수정 시각만 따로 남긴다
- 카테고리 id 없이 저장된 예전 지출도 이름으로 카테고리를 찾아 칩을 선택해 둔다 (예: "문화/여가" → 문화)
- 목록에서 눌렀는데 그사이 상대방이 지운 지출이면 수정 화면을 띄우지 않고 목록으로 돌아간다

### 삭제 플로우
1. 상단 삭제 아이콘 탭
2. 확인 팝업 노출 ("삭제하시겠어요?")
3. 확인 시 삭제 처리 → 이전 화면(전체보기)으로 복귀
4. 취소 시 팝업만 닫힘, 수정 화면 유지
