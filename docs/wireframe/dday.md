# 6. 디데이

디데이 탭은 별도 대시보드 없이, 아래 리스트 화면이 탭의 기본(랜딩) 화면 역할을 한다.

## 6-1. 디데이 리스트 (탭 랜딩 화면)

### 화면 목적
생일·기념일(프로필 자동 반영)과 직접 추가한 기념일을 D-day 형태로 한눈에 확인.

### 레이아웃 (위→아래 순서)
1. **상단 타이틀** ("디데이")
2. **디데이 리스트**
   - 가장 가까운 순으로 정렬
   - 항목 구성: D-day 숫자 강조 배지(예: "D-12") + 제목 + 날짜
   - 자동 반영 항목(생일/기념일)은 별도 아이콘/라벨로 구분 표시
3. **플로팅 액션 버튼 (+)**
   - 화면 우측 하단 고정, 탭 시 디데이 추가 화면으로 이동 (수동 추가 항목만 해당)
4. **하단 탭 내비게이션** (전 화면 공통, "디데이" 강조)

### 상태 분기 (추후 확정 필요)
- 디데이가 하나도 없을 경우 "디데이를 추가해보세요" 빈 상태 노출
- 자동 반영 항목(생일/기념일) 탭 시 이동 흐름: 바로 "설정 > 프로필 수정"으로 이동할지, 안내 팝업을 먼저 띄울지

---

## 6-2. 디데이 추가 (수동 항목만 해당)

### 화면 목적
사용자가 직접 기념일(여행, 이사 등)을 추가.

### 레이아웃 (위→아래 순서)
1. **상단 - 타이틀만 노출** ("디데이 추가"), 좌측 닫기(X) 아이콘
2. **입력 필드 리스트**
   - 제목
   - 날짜
   - 매년 반복 여부 (토글)
3. **하단 고정 버튼**: "저장하기"

---

## 6-3. 디데이 수정 (수동 항목만 해당)

### 화면 목적
직접 추가한 디데이 수정 또는 삭제. 자동 반영 항목(생일/기념일)은 이 화면에 진입하지 않고 프로필 수정으로 안내.

### 레이아웃
- **디데이 추가와 동일한 레이아웃 재사용**, 기존 값 프리필
- 상단: 좌측 뒤로가기, 우측 삭제(휴지통) 아이콘
- 하단 버튼 라벨만 "수정 완료"
