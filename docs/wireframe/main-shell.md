# 2. 메인 화면 구성 (공통 셸)

PRD 2번 "메인 화면 구성"에 대응. 홈/가계부/일정/디데이/설정 5개 탭에 공통으로 적용되는 하단 내비게이션 구조.

### 구성
- 화면 하단 고정, 5개 탭: **홈 · 가계부 · 일정 · 디데이 · 설정**
- 각 탭: 아이콘 + 라벨(텍스트) 함께 노출
- 현재 위치한 탭만 강조 색상(Primary), 나머지는 회색 톤(비활성)
- 탭 전환 시 화면은 즉시 전환 (트랜지션 애니메이션 최소화, 심플함 우선)

### 탭별 진입 화면
| 탭 | 진입 시 보여지는 화면 |
|---|---|
| 홈 | 요약 대시보드 (예산/카테고리/최근 지출) |
| 가계부 | 전체보기 (날짜별 지출 리스트) — 별도 대시보드 없음 |
| 일정 | 캘린더 월간 뷰 |
| 디데이 | 디데이 리스트 (가장 가까운 순) |
| 설정 | 설정 메뉴 리스트 |

### 플로팅 액션 버튼(+) 노출 규칙
- 가계부 탭: 지출 입력으로 연결
- 일정 탭: 일정 등록으로 연결
- 디데이 탭: 디데이 추가로 연결
- 홈, 설정 탭: 플로팅 버튼 없음

### 상태 분기 (추후 확정 필요)
- 탭이 5개로 늘어난 것에 대한 실제 사용성 검증 필요 (아이콘만으로 축소하거나 재구성 여지 있음 — PRD "남은 결정 사항" 참고)
- 뱃지(미확인 알림 등)를 탭 아이콘에 표시할지 여부 — 현재 PRD상 알림 아이콘은 홈에서 제거된 상태라 탭바 뱃지도 기본은 미적용으로 간주
