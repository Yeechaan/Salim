# 3. 홈

## 화면 목적
로그인 후 진입하는 첫 화면. 이번 달 예산 상태와 최근 지출을 한눈에 파악하는 것이 목표.

## 레이아웃 (위→아래 순서)

### 1. 상단 - 월 선택
- 텍스트: "2026년 8월" + 드롭다운 화살표
- 탭하면 다른 월로 이동 (달력 피커 또는 좌우 스와이프)

### 1-1. 상대방 연결 배너 (미연결 상태에서만)
- 월 선택 바로 아래, 예산 카드 위에 배치
- 구성: 좌측 연결 아이콘(옅은 Coral 원 배경) + "상대방을 연결해보세요" + 보조 문구("초대 코드나 QR로 함께 기록해요") + 우측 화살표
- 카드 전체가 탭 영역 — 탭 시 연결 관리 화면으로 (connect.md 9-1)
- **연결되면 배너는 사라진다.** 별도 완료 표시를 남기지 않고, 연결 상태는 설정 화면에서 확인한다
- 예산 카드보다 시각적 무게를 낮춘다(높이·그림자 축소) — 홈의 주인공은 예산 현황이고 배너는 권유다

### 2. 예산 카드
- 배경: 카드형 (surface-1)
- 내용: "이번 달 예산" 라벨 + 현재 지출액 (강조) + "/ 예산 총액" (보조)
- 라벨 우측 끝에 **연필 아이콘**(옅은 Coral 원 배경) — 카드를 탭하면 예산을 고칠 수 있다는 표시. 아이콘은 장식이고 실제 탭 영역은 카드 전체
- 진행률 바: 지출액 비율만큼 채워짐
- 하단 보조 텍스트: "남은 예산 OOO원 · OO% 사용"
- 예산 100% 초과 시 진행률 바 색상을 경고색으로 전환 (별도 규칙 필요)

### 2-1. 예산 입력 시트
- 진입: 예산 카드 탭 (예산 미설정 시 "예산을 설정해보세요" CTA 탭) → 하단 바텀시트
- 설정 > 달별 예산 설정과 **동일한 시트를 공용**으로 쓴다 (`ui/common/BudgetInputSheet`)
- 타이틀: "2026년 8월 예산"
- 금액 입력: 대형 숫자 + "원" (우측 정렬). 천단위 콤마 자동, 미입력 시 회색 `0` placeholder, 최대 10자리
  - 우측 끝에 지우기 아이콘(원형 X) — 입력값이 있을 때만 노출하고, 없을 때도 자리는 비워 둬서 금액 위치가 흔들리지 않게 한다. 탭하면 입력값 초기화
- 빠른 금액 버튼: `+1만` `+5만` `+10만` `+50만` `+100만` 칩 5개를 **한 줄에 균등 폭**으로 좌우 꽉 채워 배치 (스크롤·줄바꿈 없이 항상 5개 노출)
  - 시스템 글꼴을 크게 키우면(360dp 기준 배율 1.2 이상) `+100만` 라벨 끝이 잘릴 수 있다 — 5개 고정 노출을 우선한 결과
  - **누적 방식** — 탭할 때마다 현재 입력값에 더해진다 (예: `+50만` → `+10만` ×2 = 700,000원)
  - 직접 키패드 입력과 병행 가능
- 하단 "저장하기" 버튼 — 금액 미입력 상태에서는 비활성

### 3. 카테고리별 지출
- 좌측: 도넛(파이) 차트, 카테고리별 색상 구분
- 우측: 범례 리스트 (색상 점 + 카테고리명 + 금액), 상위 3개까지만 노출
- "카테고리별 지출 종합" 전체는 가계부 탭 또는 별도 화면에서 확인 (범위 확정 필요)

### 4. 다가오는 디데이
- 섹션 제목 "디데이" + 우측 "전체보기" 텍스트 링크 (최근 지출 내역 카드와 같은 패턴)
- 가장 가까운 디데이 1~2건 노출 (예: "결혼기념일 D-12"). 이미 지난 항목은 제외
- 카드 전체 탭(전체보기 포함) 시 **설정 > 디데이 관리**(dday.md 6-1)로 이동 — 디데이 탭은 없어졌다 (PRD 6)
- 디데이가 없으면 "디데이를 추가해보세요" — 탭하면 같은 화면으로 이동

### 5. 최근 지출 내역
- 섹션 제목 + 우측 "전체보기" 텍스트 링크 (탭 시 가계부 탭 전체보기로 이동)
- 리스트 아이템 (최근 3~5건): 상호명/메모, 카테고리 · 지출자 · 날짜(상대 표기: 오늘/어제/날짜), 금액
- 아이템 탭 시 지출 수정 화면으로 이동

### 6. 하단 탭 내비게이션 (전 화면 공통)
- 홈 / 가계부 / 일정 / 할 일 / 설정
- 현재 위치 아이콘·라벨 강조 표시

## 상태 분기 (추후 확정 필요)
- 예산 미설정 상태: 예산 카드 자리에 "예산을 설정해보세요" CTA로 대체
- 이번 달 지출 데이터 없음: 카테고리 차트·최근 내역 영역에 빈 상태(empty state) 문구 필요
