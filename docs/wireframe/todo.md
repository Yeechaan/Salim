# 11. 할 일

할 일 탭은 별도 대시보드 없이, 아래 리스트 화면이 탭의 기본(랜딩) 화면 역할을 한다. (PRD 11)

## 11-1. 할 일 리스트 (탭 랜딩 화면)

### 화면 목적
둘이 함께 챙길 일(장보기, 집안일, 준비물 등)을 적어 두고, 끝나면 체크한다.

### 레이아웃 (위→아래 순서)
1. **상단 타이틀** ("할 일") — 좌측에 탭바와 같은 체크리스트 아이콘
2. **미완료 카드**
   - 등록순(먼저 적은 것이 위)으로 나열
   - 항목 구성: 좌측 원형 체크박스 + 제목 + 메타 + (하위 항목이 있을 때만) 우측 펼침 화살표
     - 메타: (연결 상태에서만) 담당자 ("함께" / 내 이름 / 상대 이름) · (하위 항목이 있으면) 진행 "2/5". 둘 다 없으면 메타 줄을 숨긴다
   - 체크박스 탭 → 완료 처리, 완료 섹션으로 이동. **하위 항목도 모두 완료로 바뀐다**
   - 펼침 화살표 탭 → 바로 아래에 하위 항목을 들여써서 나열 (기본은 접힘, 항목마다 따로 기억)
     - 하위 항목 줄: 작은 원형 체크박스 + 제목 + (연결 상태에서만) 담당자 메타. 완료된 하위 항목은 자리를 유지한 채 취소선 + Muted
     - 순서는 추가한 순서
     - 하위 항목 체크박스 탭 → 그 하위 항목만 완료/해제. 모두 체크해도 상위 항목은 그대로 미완료
     - 하위 항목 줄의 체크박스 외 영역 탭 → 상위 항목의 11-2 수정 시트
   - 체크박스·화살표 외 영역 탭 → 11-2 수정 시트
3. **완료 섹션**
   - 헤더 "완료 N" + 펼침/접힘 화살표. **기본은 접힘**
   - 펼치면 완료 항목을 최근 완료순으로 — 체크박스 Coral 채움, 제목 취소선 + Muted 색
   - 체크 해제 → 미완료로 복귀 (등록순 자리로 돌아간다). 하위 항목 상태는 그대로
   - 완료 항목도 하위 항목이 있으면 펼칠 수 있다
   - 완료 항목이 없으면 섹션 자체를 숨긴다
4. **플로팅 액션 버튼 (+)** — 11-2 추가 시트
5. **하단 탭 내비게이션** (전 화면 공통, "할 일" 강조)

### 상태 분기
- 할 일이 하나도 없음: "할 일을 추가해보세요" 빈 상태
- 미완료는 없고 완료만 있음: 미완료 자리에 "모두 끝냈어요" 문구, 아래 완료 섹션은 그대로
- 미연결: 담당자 메타를 숨긴다 (모두 내 할 일)

## 11-2. 할 일 추가 / 수정 (바텀시트)

### 화면 목적
한두 단어짜리 할 일을 빠르게 적는다. 항목이 단순해 별도 화면 대신 시트로 연다.

### 레이아웃 (위→아래 순서)
1. **타이틀** — 추가 "할 일 추가" / 수정 "할 일 수정". 수정일 때만 우측에 삭제(휴지통) 아이콘
2. **제목 입력** — 한 줄, 자동 포커스, placeholder "할 일을 입력하세요", 최대 30자
3. **담당자** — 칩 3개 중 택1: "함께" / 내 이름 / 상대 이름 (이름 없으면 "나"/"배우자"). 기본값 "함께"
   - **미연결 상태에서는 이 줄을 숨기고 본인으로 저장한다**
4. **하위 항목** — 라벨 "하위 항목"
   - 줄마다: 한 줄 제목 입력 + (연결 상태에서만) 담당자 버튼 + 삭제(✕) 아이콘
     - 담당자 버튼은 현재 담당자 이름을 보여주고, 탭하면 "함께 / 내 이름 / 상대 이름" 메뉴가 뜬다
   - 맨 아래 "+ 하위 항목 추가" → 빈 줄이 붙고 그 줄에 포커스. 담당자 기본값은 위에서 고른 상위 항목 담당자
   - 시트에서는 체크하지 않는다 (체크는 목록에서). 순서는 추가한 순서, 최대 20개 — 다 차면 추가 버튼을 숨긴다
   - 제목을 비워 둔 줄은 저장할 때 버린다
5. **하단 버튼** — 추가 "저장하기" / 수정 "수정 완료". 상위 항목 제목이 비어 있으면 비활성

### 동작
- 저장/수정 완료 → 시트 닫힘, 목록에 바로 반영. 상위 항목과 하위 항목의 추가·수정·삭제를 한 번에 저장한다
- 수정해도 완료 여부와 목록 순서(등록순)는 바뀌지 않는다 (하위 항목도 같다)
- 상위 항목 삭제 시 하위 항목도 함께 삭제. 확인 팝업 문구에 하위 항목 개수를 덧붙인다 ("하위 항목 3개도 함께 삭제돼요.")
- 삭제 아이콘 → 확인 팝업("삭제하시겠어요?" / "삭제하면 되돌릴 수 없어요.") → 확인 시 삭제 후 시트 닫힘
- 시트를 그냥 내리면 입력은 버린다
- 수정 중 상대방이 그 항목을 지우면 시트를 닫는다
