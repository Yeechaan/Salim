# 10. 홈 화면 위젯 (OS 위젯)

앱 밖(OS 홈 화면)에 놓는 위젯. 1차는 **디데이**·**예산** 소형 2종. (PRD 10)

## 공통

- 크기: 기본 2×2 칸, 가로·세로 늘리기 가능. 두 위젯을 나란히 놓으면 한 줄을 채운다
- **가로형 2×1**: 세로를 한 칸으로 줄이면 한 줄짜리 레이아웃으로 바뀐다 (각 위젯의 "가로형" 참고). 1×1은 두지 않는다
- 흰 카드(홈 카드와 같은 24dp 모서리) 한 장
- 상단 라벨: 아이콘(Coral) + 위젯 이름 (보조 텍스트색, 작게). 본문은 카드 아래쪽에 붙인다
- 위젯 어디를 탭해도 앱이 열린다. 로그인 전이면 로그인/온보딩 화면으로 간다
- 로그아웃 상태: 데이터가 없으므로 각 위젯의 빈 상태와 같게 보인다
- 불러오기 실패: "앱을 열어 확인해주세요" — "없음"과 구분해 잘못된 빈 상태를 보이지 않는다

### 갱신 시점
- 자정이 지나면 다시 계산 (D-숫자, 이번 달). 시간·시간대 변경 시에도
- 앱이 켜져 있는 동안 데이터가 바뀌면 즉시 (상대방이 바꾼 것 포함)
- 앱이 꺼져 있을 때 상대방이 바꾼 내용은 다음에 앱을 열 때 반영 — 서버 푸시 기반 갱신은 알림(PRD 8) 작업 때 함께 검토

## 10-1. 디데이 위젯

### 화면 목적
앱을 열지 않고 가장 가까운 기념일까지 남은 날을 확인.

### 레이아웃 (위→아래 순서)
1. **상단 라벨** — 선물 아이콘 + "디데이"
2. **D-day 숫자** — "D-12", Coral, 가장 크게
3. **제목** — 예: "결혼기념일", 한 줄 (넘치면 잘림)
4. **날짜** — "2026.10.09", 보조 텍스트색 (매년 반복이면 다가오는 기념일 날짜)

```
┌──────────────┐
│ 🎁 디데이      │
│              │
│ D-12         │
│ 결혼기념일     │
│ 2026.10.09   │
└──────────────┘
```

### 표시 대상
- 디데이 관리(dday.md 6-1)와 같은 목록 — 직접 추가 + 프로필 생일/기념일 자동 반영
- 가장 가까운 **다가오는** 1건. 이미 지난 항목은 제외 (홈 디데이 카드와 같은 기준, home.md 4)

### 당일 (D-DAY)
- 카드 배경을 **Coral**로 채우고 글자·아이콘은 흰색
- 2 자리에 "D-DAY", 3 자리에 **"오늘은 {제목}"** (예: "오늘은 결혼기념일"), 4 날짜는 그대로

### 가로형 (2×1)
- 윗줄: 선물 아이콘 + 제목(한 줄, 전체 폭) / 아랫줄: 날짜 — 우측에 D-day 숫자 크게
- 2칸 폭은 좁아서 제목과 D-숫자를 한 줄에 두면 제목이 잘린다 — 그래서 두 줄로 나눈다
- 당일 강조·빈 상태 규칙은 같다 (빈 상태는 아이콘 + "디데이를 추가해보세요" 한 줄)

```
┌──────────────────┐
│ 🎁 웨딩스냅 제주도  │
│ 2026.11.05  D-39 │
└──────────────────┘
```

### 상태 분기
- 디데이 없음(또는 모두 지남): 2~4 대신 "디데이를 추가해보세요"

### 동작
- 탭 → **설정 > 디데이 관리**(dday.md 6-1). 뒤로가기 시 홈 탭

## 10-2. 예산 위젯

### 화면 목적
앱을 열지 않고 이번 달 예산이 얼마나 남았는지 확인.

### 레이아웃 (위→아래 순서)
1. **상단 라벨** — 지갑 아이콘 + "{M}월 예산" (예: "9월 예산")
2. **남은 금액** — "452,000원", 본문색, 가장 크게 / 그 아래 "남음" (보조 텍스트색)
   - 초과 시: "38,000원" + "초과" — 둘 다 **경고색**
3. **진행률 바** — 사용률만큼 채움. 위젯은 그라데이션을 그릴 수 없어 **Coral 단색** (홈 카드는 Peach→Coral). 100% 초과 시 경고색으로 가득
4. **사용률** — "62% 사용" (보조 텍스트색)

```
┌──────────────┐
│ 👛 9월 예산    │
│              │
│ 452,000원     │
│ 남음          │
│ ██████░░░░   │
│ 62% 사용      │
└──────────────┘
```

### 가로형 (2×1)
- 세 줄: 지갑 아이콘 + "{M}월 예산" / "452,000원 남음" (초과면 "38,000원 초과", 경고색) / 진행률 바
- 사용률 줄은 뺀다. 금액 가리기면 가운데 줄이 "62% 사용"

```
┌──────────────────┐
│ 👛 9월 예산        │
│ 452,000원 남음     │
│ ██████░░░░░░░    │
└──────────────────┘
```

### 계산
- 홈 예산 카드(home.md 2)와 같다 — 이번 달 지출 합계 ÷ 이번 달 예산. 지출자(나/상대/우리) 구분 없이 전체

### 금액 가리기 (설정 > "위젯에 금액 표시" 끔)
- 2를 빼고 **사용률을 크게** ("62%" + "사용"), 진행률 바는 그대로
- 초과 시에도 금액 없이 "108%" + "초과" (경고색)
- 이 기기의 위젯에만 적용 (상대방 위젯에는 영향 없음)

### 상태 분기
- 이번 달 예산 없음: 2~4 대신 "이번 달 예산을 설정해보세요"

### 동작
- 탭 → **홈 탭** (예산 카드가 있는 화면)
