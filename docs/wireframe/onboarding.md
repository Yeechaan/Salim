# 1. 온보딩 및 로그인

PRD 1번 "온보딩 및 로그인" 항목에 대응. 앱 미설치/미로그인 상태에서의 첫 진입 흐름.

## 1-1. 온보딩 - 가치 소개

### 화면 목적
앱의 핵심 가치(공동 가계부/일정)를 첫 화면에서 전달.

### 레이아웃
- 중앙: 아이콘/일러스트 자리 + 타이틀("둘이 함께 쓰는 가계부") + 보조 설명("지출과 일정을 한눈에")
- 하단: 페이지 인디케이터(점 2개 중 1번째 강조) + "다음" 버튼

---

## 1-2. 온보딩 - 연결 안내

### 화면 목적
상대방 연결 방식을 미리 안내 (이 시점엔 실제 연결 액션 없음, 설명만).

### 레이아웃
- 중앙: 아이콘(연결 표시) + 타이틀("초대코드나 QR로 상대방과 연결") + 보조 설명("로그인 후 언제든 연결할 수 있어요")
- 하단: 페이지 인디케이터(점 2개 중 2번째 강조) + "시작하기" 버튼 → 로그인 화면으로 이동

---

## 1-3. 로그인

### 화면 목적
구글 로그인으로 서비스 진입. (카카오 로그인은 추후 적용 예정 — PRD 1번 참고)

### 레이아웃
- 중앙: 앱 로고 자리 + 앱 이름("같이살림") + 슬로건("함께 보는 우리 가계부")
- 하단: "Google로 계속하기" 버튼(구글 로그인 가이드라인 준수) + 약관 동의 안내 문구(작은 글씨)

### 상태 분기 (추후 확정 필요)
- 로그인 실패/취소 시 처리 (에러 문구, 재시도)
- 최초 로그인(회원가입) vs 재로그인 분기 필요 여부
- 동일 이메일의 다른 로그인 방식 연동 시 계정 연결(linking) UX (추후 카카오/애플 등 추가 시 논의)
