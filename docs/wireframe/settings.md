# 7. 설정

## 화면 목적
프로필, 카테고리, 예산, 알림, 연결 상태 등 앱 전반의 설정을 관리.

## 레이아웃 (위→아래 순서)
1. **상단 타이틀** ("설정")
2. **연결 상태 카드**
   - 연결됨: 프로필 아이콘 2개 겹침 표시 + "배우자와 연결됨" + 연결일(예: "2025.03.14부터 함께 기록 중")
   - 미연결: "상대방을 연결해보세요" CTA로 대체 (온보딩 2번, 홈 배너와 동일 맥락)
   - 탭 시 연결 관리 화면으로 이동 (connect.md 9-1)
3. **"일반" 그룹**
   - 프로필 수정 (이름, 생일, 기념일 — 이름은 가계부 지출자 표시, 생일/기념일은 디데이 자동 반영과 연결)
     - 우측 값에는 설정한 이름을 노출한다. 이름이 없으면 "이름 · 생일 · 기념일"
     - 이름 입력은 한 줄 텍스트(최대 12자) — 지출자 칩 한 줄에 두 사람 이름이 들어가야 한다
   - 가계부 카테고리 수정 → 3-2 카테고리 수정 화면
   - 달별 예산 설정 (우측에 현재 설정값 노출, 예: "1,200,000원")
   - 알림 설정
4. **"연결" 그룹**
   - 연결 해제 (경고색 텍스트로 구분)
   - **1차에서는 비활성**("준비 중")으로만 노출한다 — 30일 유예 삭제에 서버 작업이 필요 (PRD 9 "1차 구현 범위")
5. **하단 — 로그아웃 / 회원탈퇴**
   - 목록과 시각적으로 분리(여백 또는 구분선)해서 실수로 누르지 않도록 배치
   - 회원탈퇴는 로그아웃보다 더 낮은 강조(작은 텍스트, 무채색)로 처리
6. **하단 탭 내비게이션** (전 화면 공통, "설정" 강조)

## 3-2. 카테고리 수정

### 화면 목적
지출 입력에 나오는 카테고리를 우리 가계부에 맞게 고친다. (PRD 7) 진입점은 설정 "가계부 카테고리 수정"과 지출 입력의 "+더보기" 시트 우측 상단 "편집" 두 곳.

### 레이아웃 (위→아래 순서)
1. **상단** — 좌측 뒤로가기, 타이틀 "카테고리 수정". 별도 저장 버튼 없음 (항목마다 바로 저장)
2. **안내 문구** — "고정 항목은 지출 입력에서 칩으로 바로 보여요. 항목을 누르면 이름을 바꿀 수 있어요."
3. **"고정 항목" 카드** — 5개 줄 (아이콘 + 이름). 줄 탭 → 이름 수정 창
4. **"더보기 항목" 카드** — 줄마다 아이콘 + 이름 + 우측 "고정으로" 텍스트 버튼. 줄 탭 → 이름 수정 창
   - 카드 맨 아래 "+ 항목 추가" → 항목 추가 창. 새 항목은 더보기 맨 끝에 붙고 공용 아이콘을 쓴다
```
← 카테고리 수정
고정 항목
  🍽 식비
  ☕ 카페
  …
더보기 항목
  🚌 교통            고정으로
  🧹 생활            고정으로
  …
  + 항목 추가
```

### 고정 교체 ("고정으로")
- 고정 항목은 **항상 5개**. 더보기 항목의 "고정으로" 탭 → 바텀시트 "어떤 항목과 바꿀까요?" + 고정 5개 칩
- 칩을 고르면 두 항목이 **자리째 맞바뀐다** — 올라온 항목이 내려간 항목의 칩 자리에, 내려간 항목은 더보기 쪽 그 자리에

### 이름 입력 창 (추가 / 이름 수정 공용)
- 한 줄 입력 + 우측 글자 수 "3/8". **8자에서 더 입력되지 않는다** (프로필 이름 입력과 같은 방식)
- 확인 시 검증하고, 통과해야 닫힌다: 빈 이름 "이름을 입력해주세요"(확인 버튼도 비활성) / 같은 이름 "이미 있는 이름이에요" (자기 이름 그대로 저장은 허용)
- 이름을 바꾸면 **기존 지출에도 새 이름**이 보인다 (PRD 7)

### 1차 범위 밖
- 삭제 / 사용 중지 (PRD 7 삭제 정책), 순서 직접 변경, 아이콘 선택

## 상태 분기 (추후 확정 필요)
- 회원탈퇴 탭 시 확인 절차 (비밀번호 재입력 등 추가 인증 필요 여부)
- 연결 해제/회원탈퇴 확인 팝업에 유예기간(30일) 안내 문구 포함 (PRD 9번 참고)
