# 5. 일정

일정 탭은 별도 대시보드 없이, 아래 캘린더 화면이 탭의 기본(랜딩) 화면 역할을 한다.

## 5-1. 캘린더 (탭 랜딩 화면)

### 화면 목적
월간 캘린더로 우리 일정/개인 일정을 한눈에 확인하고, 날짜를 선택해 상세 일정을 본다.

### 레이아웃 (위→아래 순서)
1. **상단 - 월 선택 + 필터 칩**
   - 좌: "2026년 8월" + 드롭다운 (월 변경)
   - 우: "우리 일정" / "개인" 필터 칩 (토글, 복수 선택 가능)
2. **월간 캘린더 그리드**
   - 요일 헤더(일~토) + 날짜 셀
   - 일정이 있는 날짜엔 하단에 작은 색상 점 표시 (일정 유형별 색 구분)
   - 선택된 날짜는 원형 강조(배경색)로 표시
3. **선택 날짜의 일정 리스트**
   - 날짜 헤더 (예: "8월 5일 (화)")
   - 항목 구성: 좌측 색상 바(유형 구분) + 제목 + 시간·유형(우리 일정/배우자 개인 등) 메타 정보
4. **플로팅 액션 버튼 (+)**
   - 화면 우측 하단 고정, 탭 시 일정 등록 화면으로 이동
5. **하단 탭 내비게이션** (전 화면 공통, "일정" 강조)

### 상태 분기 (추후 확정 필요)
- 선택 날짜에 일정 없음: "등록된 일정이 없어요" 빈 상태 노출
- 색상 구분 규칙: 우리 일정 / 개인(나) / 개인(배우자) — 3가지 색이 모두 필요한지, 2가지(우리·개인)로 단순화할지

---

## 5-2. 일정 등록

### 화면 목적
새 일정 1건 등록.

### 레이아웃 (위→아래 순서)
1. **상단 - 타이틀만 노출** ("일정 등록"), 좌측 닫기(X) 아이콘
2. **입력 필드 리스트** (구분선으로 구획)
   - 제목
   - 날짜 (선택한 날짜가 기본값)
   - 시간 (종일 여부 토글 포함 검토)
   - 유형 — "우리 일정" / "개인(나)" / "개인(배우자)" 중 택1, 칩 형태
3. **하단 고정 버튼**: "저장하기"

### 상태 분기 (추후 확정 필요)
- 종일 일정 지원 여부
- 반복 일정(매주/매월 등) 지원 여부 — 1차 범위 제외 검토

---

## 5-3. 일정 수정

### 화면 목적
기존 일정 1건 수정 또는 삭제.

### 레이아웃
- **일정 등록과 동일한 레이아웃 재사용**, 기존 값 프리필
- 상단: 좌측 뒤로가기, 우측 삭제(휴지통) 아이콘
- 하단 버튼 라벨만 "수정 완료"

### 삭제 플로우
가계부 지출 수정과 동일 (확인 팝업 → 삭제 → 이전 화면 복귀)
