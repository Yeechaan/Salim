상대방 연결 (PRD 9)

- 초대 코드 발급 / QR 표시 / 공유하기
- 코드 입력 + QR 스캔으로 연결
- 연결되면 가계부·일정·디데이·예산이 공동 데이터로 전환

테스트 시 확인해 주세요
1. 설정 > 연결 상태 카드 또는 홈 배너로 연결 화면 진입
2. 한쪽이 "초대 코드 만들기" → 다른 쪽이 코드 입력 또는 QR 스캔
3. 연결 직후 양쪽 화면이 완료로 넘어가는지
4. 연결 뒤 등록한 지출이 상대에게도 보이는지 (연결 전 기록은 각자 것만 보이는 게 정상)
5. 지출 입력의 "지출자", 일정 등록의 "유형"이 연결 후에만 보이는지

알려진 제약
- 초대 코드 유효기간 30분, 1회용
- 연결 해제와 연결 성공 푸시 알림은 아직 없음
